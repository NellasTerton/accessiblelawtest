Подключить проект к GitHub и создать репозиторий с двусторонней синхронизацией.

Технические детали:
- Действие выполняется через UI Lovable, а не через код в проекте.
- Lovable синхронизирует код в созданный репозиторий автоматически.

Шаги:
1. В Lovable-редакторе открыть меню «+» в левом нижнем углу чата → выбрать GitHub.
2. Авторизовать Lovable GitHub App на своём аккаунте GitHub.
3. Выбрать аккаунт/организацию, в которой будет создан репозиторий.
4. Нажать «Create Repository» — Lovable создаст новый репозиторий и запустит двустороннюю синхронизацию.
5. Проверить, что код появился в репозитории на GitHub.

После подключения любые изменения в Lovable будут автоматически отправляться в GitHub, а изменения, запушенные в активную ветку GitHub, будут синхронизироваться обратно в Lovable.
