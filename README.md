## ⚡ Основной функционал
*   **Управление лидами:** Добавление клиентов (Имя, Телефон, Статус) через модальное окно.
*   **Динамические статусы:** Изменение статуса («Новый», «В работе», «Закрыт») прямо в таблице.
*   **Аналитика:** Автоматический подсчет и вывод счетчиков по каждому статусу в хедере.
*   **Данные:** Использование `LocalStorage` для хранения состояния без развертывания тяжелой БД.

## 🤖 Бонус: Автоматизация процессов
Реализовано автоматическое push-уведомление при добавлении нового клиента.
Вместо закрытого бота уведомления направляются в открытый Telegram-канал (ссылка доступна в интерфейсе дашборда), чтобы ревьюер мог протестировать флоу в реальном времени.

**Пайплайн автоматизации:**
Frontend (Fetch POST) ➔ Webhook ➔ Make.com ➔ Telegram Bot API ➔ Публичный канал.

## 🛠 Технический стек
*   **Frontend:** React, TypeScript, Tailwind CSS (Сгенерировано через Lovable).
*   **Автоматизация:** Make.com, Telegram API.
